===================================================================
  HUSTLE CASTLE BOT  --  Guide 3 of 5: EVERYDAY COMMANDS
===================================================================
  START
     !start dungeon 5          five dungeon runs, random partner
     !start dungeon 10 lisa   ten runs with your friend Lisa
     !start cathedral 3        cathedral, all bosses
     !start cathedral 3 c      cathedral, turbo (fastest)
     !start arena 5            five arena tournaments
     !start event              hammer event until the hammers are gone
     !start eventloop          cathedral -> event -> ... in a loop
     !after dungeon 20         start this when the current job ends

  CONTROL
     !pause  /  !resume        hold  /  carry on
     !stop                     stop and empty the queue
     !emergency                stop at once
     !castle                   finish the run, back to the castle
     !queue                    what is waiting

  LOOK
     !status                   what is running
     !stats                    numbers and times
     !screenshot  /  !live     picture of the game
     !log                      error report as a file

  CLAN WAR
     !clanwar on / off         deploys your squads by itself

  PC
     !end 06:30                stop after the run at 06:30
     !off 06:30                then also shut the PC down
     !off delete               take it back

  Every command and more:  !help all

===================================================================
  BUTTONS INSTEAD OF TYPING (control window, new in 3.2)
  Tab "Control": pick mode, number, route, payment and press Start.
  The line next to it shows the command it sends (e.g.
  !start cathedral 10 c). "Add after" = !after. Buttons Pause, Stop,
  EMERGENCY, Queue, Quit bot, Status, Statistics, Screenshot, Help.
  The field "Command like in Discord" takes ANY command from this guide.
  Every answer appears in the tab "Messages" -- with Discord AND without.
  Dangerous commands (!off, !pc, !emergency, !clear) ask first.
