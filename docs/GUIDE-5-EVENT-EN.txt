  HUSTLE CASTLE BOT  --  Guide 5 of 5: EVENT LOOP
===================================================================
  The event loop plays everything by itself: the cathedral over and
  over, the hammer event in between, lighthouse, colosseum, titan
  tower and -- if you switch it on -- the clan war.

  SET UP ONCE
     !settings foodlimit cathedral 15m   stop paying food below 15 million
     !clanwar on                         deploy for the clan war by itself
     !settings                           everything at a glance

  START
     !start eventloop c all
         eventloop = cathedral in a loop, with the hammer event
         c         = fastest route through the cathedral (turbo)
         all       = keys, then food, then food chests
     It plays until everything is used up. No number of runs needed.

  ONLY THE HAMMER EVENT
     !start event              until the hammers are gone

  STOP
     !stop
